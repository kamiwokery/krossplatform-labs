## Контрольные вопросы (ответы)

1. **Что такое наследование?** Отношение между классами, при котором характеристики одного класса (суперкласса) передаются другому (подклассу) без повторного определения. Подкласс наследует поля и методы суперкласса, как будто они находятся в нём самом, и дополняет их своими членами и/или переопределяет методы.
2. **Какие ключевые слова используются?** `extends` — наследование класса; `super` — обращение к конструктору/полю/методу суперкласса (первым словом в конструкторе); `this` — ссылка на текущий объект; `implements` — реализация интерфейса. Множественное наследование классов запрещено; без `extends` класс наследует `Object`.
3. **Какие члены не наследуются подклассом?** Члены `private` (во всех случаях) и `default` для подкласса в другом пакете. Также не наследуются конструкторы — они вызываются из конструктора подкласса через `super(parameters)`.

## Теория в коде

- `extends` — объявление производных классов.
- `super(name, material, price)` — вызов конструктора суперкласса.
- `super.displayInfo()` — вызов метода суперкласса; `@Override` — переопределение `getPurpose()`.
- `instanceof` + приведение типа `(Table) f` — доступ к уникальным методам подкласса из массива базового типа.
