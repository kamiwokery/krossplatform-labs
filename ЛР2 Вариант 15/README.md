## Как открыть и запустить в IntelliJ IDEA

1. Запустите IntelliJ IDEA.
2. `File` → `Open...` → выберите папку `ЛР2 Вариант 15` на рабочем столе → `OK`.
3. Укажите JDK в поле `Project SDK`.
4. Откройте `Task1.java` → зелёный треугольник слева от `public class Task1` → `Run`.
5. Ввод данных — в окне консоли внизу.

## Контрольные вопросы (ответы)

1. **Способы создания массивов:**
   - через `new`: `int[] a = new int[10];`
   - через список инициализации: `int[] a = {1, 2, 3, 4};` или `int[] a = new int[] {1, 2, 3, 4};`
   - двухмерный: `int[][] m = new int[3][3];` или `int[][] m = {{1,2},{3,4}};`
2. **Как можно заполнять массив:**
   - значениями по умолчанию при `new` (для `int` — 0, для `boolean` — `false`, для объектов — `null`)
   - списком инициализации при создании
   - вручную по индексу: `a[i] = значение;`
   - через цикл `for` (по `length`)
   - через `Scanner` (с клавиатуры) или случайными числами
3. **Типы литералов Java:** арифметические (суффиксы `l/L` — long, `f/F` — float, `d/D` — double), логические (`true`, `false`), строковые (в двойных кавычках `"abc"`), символьные (в апострофах `'a'`).

## Теория в коде

- `Task2` — двумерный массив «массив массивов»: `length` строк и столбцов, вложенные циклы, обращение `matrix[i][j]`.
