## Контрольные вопросы (ответы)

1. **Что такое строка?** Упорядоченная последовательность символов. В Java строка — объект (`String`), основной носитель текстовой информации.
2. **Как создается строка?** Через оператор `new` (`new String("...")`) или через литерал (`"Эта строка создана литералом"`). Литералы возможны только для класса `String`.
3. **Как выглядит массив строк?** `String[] auto = {"Маша", "Петя", "Вася"};` — массив ссылок на объекты `String`.
4. **Что такое конкатенация?** Слияние нескольких строк в одну. Результат — новая строка.
5. **Как происходит слияние строк?** Операторами `+` и `+=` (единственные перегруженные операторы в Java) или методом `concat()`.
6. **Какие классы работают с регулярными выражениями?** `java.util.regex.Pattern` (шаблон, `compile`, `matcher`, `split`, `matches`) и `java.util.regex.Matcher` (поиск `find`, `lookingAt`, группы `group`, замена `replaceAll`, сброс `reset`).
