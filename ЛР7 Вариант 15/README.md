## Контрольные вопросы (ответы)

1. **Как создается и вызывается статическое поле:** перед типом поля пишется ключевое слово `static`: `static int totalPlanets = 0;`. Обращение вне класса — по имени класса: `Planet.totalPlanets` (внутри класса — просто по имени). Память выделяется при загрузке класса, даже если ни один объект не создан.
2. **Как создается и вызывается статический метод:** объявляется с `static`: `public static double getAverageMoons() {...}`. Вызывается через имя класса без создания объекта: `Planet.getAverageMoons()`. Статический метод может обращаться только к статическим полям и методам (обратное не верно).
3. **Отличие от нестатических:** обычные (нестатические) поля хранят состояние конкретного объекта и создаются в отдельной копии для каждого объекта; статические — состояние всего класса, существуют в единственном экземпляре, общие для всех объектов. Обычные методы работают через `this`, статические вызываются по имени класса.

## Теория в коде

- `Planet.totalPlanets`, `Planet.totalMoons` — статические поля, общие для всех планет, растут в конструкторе.
- `Planet.getAverageMoons()`, `Planet.printStatistics()` — статические методы, вызываются через имя класса.
- `name`, `diameter`, `moons` + геттеры — обычные поля конкретного объекта.
