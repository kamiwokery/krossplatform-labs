## Контрольные вопросы (ответы)

1. **Что такое инкапсуляция?** Принцип ООП: данные и методы объединяются в классе, а доступ к данным извне сокрыт (`private`) и осуществляется только через публичные методы. Защищает данные от неправомерного/случайного изменения.
2. **Что такое иерархия классов?** Система классов, связанных отношениями «родитель — потомок» (наследования): общий базовый класс и производные от него классы.
3. **Как наследуются поля и методы классов?** Производный класс получает поля и методы суперкласса: `public` и `protected` — напрямую, `private` — недоступны напрямую, но доступны через унаследованные публичные методы.
4. **Модификаторы доступа:**
   - `public` — доступен всем классам всей программы;
   - `default` (без модификатора) — виден в пределах своего пакета;
   - `protected` — как default + доступен классам-наследникам (даже из другого пакета);
   - `private` — виден только внутри самого класса.
5. **Геттеры и сеттеры:** геттер (`getX()`) — публичный метод чтения private-поля, возвращает значение; сеттер (`setX(...)`) — метод записи, позволяет валидировать данные (например, не менять значение вне допустимого диапазона).
6. **`public`** — публичный, доступен всем: классы из любого пакета могут читать/менять данные и вызывать методы.
7. **`default`** — по умолчанию (когда модификатор не указан); данные видны в пределах пакета.
8. **`protected`** — защищённый: виден в своём пакете (как default) и в классах-наследниках других пакетов.
9. **`private`** — частный: виден только самому классу; внешний доступ только через геттеры/сеттеры.
