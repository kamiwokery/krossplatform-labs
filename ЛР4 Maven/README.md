# Лабораторная работа № 4 — Проект Maven

**Тема:** Разработка, отладка и испытание программ с использованием системы сборки проекта Maven
**Дисциплина:** Основы кроссплатформенного программирования
**Среда разработки:** IntelliJ IDEA

## Задание

Сгенерировать проект с помощью Maven. Фразу `Hello, world` заменить на `Hello, ИМЯ`. Скомпилировать, запустить.

В проекте фраза заменена на `Hello, Linan!` (файл `src/main/java/org/example/App.java`). Своё имя можно поменять в этом же файле, изменив текст в кавычках.

## Структура проекта

```
ЛР4 Maven/
├── pom.xml                          — файл описания проекта Maven (POM)
└── src/main/java/org/example/
    └── App.java                     — исходный код с методом main
```

## Как открыть и запустить в IntelliJ IDEA

1. Запустите IntelliJ IDEA.
2. `File` → `Open...` → выберите папку `ЛР4 Maven` (или сам `pom.xml`) на рабочем столе → `OK`.
3. Нажмите **Trust Project**. IDEA распознает проект Maven (справа появится панель Maven).
4. Укажите JDK в поле `Project SDK` (при необходимости IDEA скачает Maven сама).
5. Откройте `src/main/java/org/example/App.java` → зелёный треугольник слева от `public class App` → `Run 'App.main()'`.
6. В консоли появится: `Hello, Linan!`

## Команды Maven (в командной строке, из папки проекта)

> В IDEA встроены JDK и Maven, поэтому отдельно устанавливать их не обязательно. Для команд в системной консоли нужно добавить Java и Maven в переменную PATH (или использовать терминал внутри IDEA).

| Команда | Назначение |
|---------|------------|
| `mvn validate` | проверка, вся ли информация доступна для сборки |
| `mvn clean` | удаление всех скомпилированных файлов из каталога `target` |
| `mvn compile` | компиляция файлов исходного кода |
| `mvn test` | запуск тестов |
| `mvn package` | упаковка в jar/war в каталоге `target` |
| `mvn verify` | проверки готовности упакованного файла |
| `mvn install` | установка пакета в локальный репозиторий |
| `mvn site` | создание документации проекта |
| `mvn deploy` | копирование архива в удалённый репозиторий |

После `mvn package` программу можно запустить из консоли:

```
java -jar target/hello-maven-1.0-SNAPSHOT.jar
```

В IntelliJ IDEA команды Maven доступны в панели **Maven** справа (двойной клик по нужной фазе) или через терминал IDE (`Terminal` → `mvn package`).

## Контрольные вопросы (ответы)

1. **Что такое Gradle?** Открытая система автоматизации сборки, использует язык на базе Groovy (файлы `build.gradle`), граф зависимостей задач (DAG), инкрементные сборки. С 2013 года — система сборки для Android.
2. **Что такое Maven?** Инструмент автоматизации сборки проектов на Java. Описывает проект XML-файлом POM (модель, зависимости, порядок сборки, плагины), загружает библиотеки из репозиториев (Maven Central) в локальный кэш. Имеет стандартную структуру каталогов и фиксированную модель фаз.
3. **В чём их отличие?** Maven — фиксированная линейная модель фаз, конфигурация XML; простое управление зависимостями, много плагинов. Gradle — граф задач на Groovy, инкрементальная сборка, гибкость и настраиваемая структура каталогов, но меньше плагинов и специалистов.
4. **Команды для работы:** `clean`, `validate`, `compile`, `test`, `package`, `verify`, `install`, `site`, `deploy` (см. таблицу выше).

## Теория в коде

- `pom.xml` — POM: `groupId`/`artifactId`/`version` (GAV), свойства `maven.compiler.*`, кодировка UTF-8, плагин `maven-jar-plugin` с указанием `Main-Class`.
- `App.java` — класс в пакете `org.example`, метод `main` — точка входа.
