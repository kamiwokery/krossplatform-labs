## Как открыть и запустить в IntelliJ IDEA

1. Запустите IntelliJ IDEA.
2. `File` → `Open...` → выберите папку `ЛР14 Вариант 15` на рабочем столе → `OK` (Trust Project).
3. Укажите JDK в поле `Project SDK`.
4. Откройте нужный `TaskN.java` → зелёный треугольник → `Run`.

## Контрольные вопросы (ответы)

1. **Поток (stream) в Java:** абстракция источника/приёмника данных, принимающего/производящего данные порциями; скрывает механизм реализации, позволяет одинаково работать с файлами, консолью, сетью — код не меняется при смене источника.
2. **Базовые абстрактные классы:** байтовые потоки — `InputStream` и `OutputStream`; символьные (Unicode) — `Reader` и `Writer`.
3. **Основные методы `InputStream`:** `read()` (один байт, `-1` — конец потока), `read(byte[])`, `read(byte[], int, int)`, `skip(long)`, `available()`, `close()`, `mark(int)`, `reset()`, `markSupported()`.
4. **Основные методы `OutputStream`:** `write(int)`, `write(byte[])`, `write(byte[], int, int)`, `flush()` (сброс буфера), `close()`.
5. **Класс `File`:** хранение и обработка имён файлов/каталогов и свойств (размер, дата, права, путь, создание/удаление/переименование); не работает с содержимым файла.
6. **`FileInputStream` и `FileOutputStream`:** чтение байтов из файла / запись байтов в файл; при открытии `FileOutputStream` без второго аргумента содержимое существующего файла стирается (дозаписи штатным конструктором нет — нужен `FileOutputStream(file, true)`), `mark/reset` в `FileInputStream` не поддерживаются.
7. **Буферизованные потоки:** `BufferedInputStream`/`BufferedOutputStream` добавляют внутренний буфер — уменьшают число обращений к диску/устройству, ускоряют последовательный ввод-вывод.
8. **`Path`/`Files` (java.nio) vs `File`:** `Files` — статические утилиты (`readString`, `write`, `walk`, `find`, `copy`), `Path` — более функциональный аналог `File`; поддерживаются атрибуты, кодировки, стримы обхода дерева, свойства потокобезопасности.
9. **Так много классов I/O:** потоковая концепция требует комбинаций «источник × способ доступа» (файл/сеть/память/консоль × побайтовый, пословный, построчный, буферный, случайный), поэтому иерархия классов разделена на байтовые/символьные и утилиты-декораторы.
10. **try-catch обязателен и try-with-resources:** методы потоков генерируют checked `IOException`; `try (A a = ...; B b = ...) { }` автоматически вызывает `close()` у всех перечисленных ресурсов в обратном порядке даже при исключении (классы реализуют `AutoCloseable`).

## Теория в коде

- `java.io.File`: свойства файла (`length`, `exists`, `canRead/canWrite`, `isFile`, `lastModified`);
- `Files.writeString`, `Files.readAllLines`, `Files.write` с `StandardCharsets.UTF_8`;
- `try-with-resources` для `Scanner`;
- обработка `IOException` через `try-catch`;
- побайтовый/построчный разбор чисел из файла.
