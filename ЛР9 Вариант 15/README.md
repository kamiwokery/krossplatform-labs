## Контрольные вопросы (ответы)

1. **Что такое абстрактный класс?** Класс, объявленный с ключевым словом `abstract`, служащий базой для иерархии реализаций. Может содержать поля, конструкторы, конкретные и абстрактные методы. Объявляет контракт требований для подклассов.
2. **Можно ли создать объект абстрактного класса?** Нет, `new AbstractClass()` — ошибка компиляции. Можно объявить ссылку и инициализировать только объектом производного класса.
3. **Что такое абстрактный метод?** Метод без тела (`public abstract void makeSound();`), определяющий только сигнатуру. Реализуется в первом конкретном наследнике.
4. **Может ли абстрактный класс иметь конструктор?** Да. Он не вызывается напрямую, а выполняется через `super()` в конструкторе наследника для инициализации полей.
5. **Может ли абстрактный класс не иметь абстрактных методов?** Да, формально может (смысл — запретить инстанцирование), но обычно нет.
6. **Какой класс должен реализовать все абстрактные методы?** Первый конкретный (не abstract) класс-наследник. Если не реализует — он тоже должен быть `abstract`.
7. **Можно ли объявить абстрактный метод как `private`?** Нет — наследники должны его переопределять (как и `static`, `final`).
8. **Можно ли `static`?** Нет — статические методы не переопределяются.
9. **Можно ли `final`?** Нет — финальные методы нельзя переопределять.
10. **Что произойдёт, если наследник не реализует абстрактный метод?** Ошибка компиляции, пока класс не будет объявлен как `abstract`.
11. **Как вызвать конструктор абстрактного класса из наследника?** Первой строкой конструктора наследника: `super(аргументы);` — вызывается только один раз и только первым.

## Теория в коде

- `abstract class Meal` — объявление абстрактного класса и методов `;` вместо `{}`.
- `extends Meal` + `super(...)` — наследование и вызов конструктора абстрактного класса.
- `@Override` — реализация абстрактных и переопределение конкретного метода.
- `Meal[] meals` — массив абстрактного типа, полиморфные вызовы `m.cook()`, `m.getCaloriesPer100g()`, `m.displayInfo()`.
