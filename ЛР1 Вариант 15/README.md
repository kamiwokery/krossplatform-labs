## Как открыть и запустить в IntelliJ IDEA

1. Запустите IntelliJ IDEA.
2. `File` → `Open...` → выберите папку `ЛР1 Вариант 15` на рабочем столе → `OK`.
3. В поле `Project SDK` укажите установленный JDK (если IDEA предложит — разрешите настройку проекта).
4. Откройте, например, `Task1.java` и нажмите зелёный треугольник слева от `public class Task1` → `Run 'Task1.main()'`.
5. Ввод данных выполняется в окне консоли внизу.

## Контрольные вопросы (ответы)

1. **Базовые типы данных Java** — их восемь: `boolean`, `byte`, `char`, `short`, `int`, `long`, `float`, `double`. Размеры: 8, 8, 16, 16, 32, 64, 32, 64 бит. Все инициализируются значениями по умолчанию (`false`, `0`, `'\u0000'`, `0`, `0`, `0`, `0.0F`, `0.0D`).
2. **Операции инкремента и декремента** — `++` и `--`. Префиксная форма (`++y`) возвращает значение после изменения, постфиксная (`y++`) — значение до изменения. `y++` эквивалентно `y = y + 1`.
3. **Типы литералов Java** — арифметические (суффиксы `l/L` — long, `f/F` — float, `d/D` — double), логические (`true`, `false`), строковые (в двойных кавычках), символьные (в апострофах, например `'F'`).
4. **Дескрипторы комментариев Java** — `@author` (об авторе), `@exception` (исключение), `@param` (параметры метода), `@return` (возвращаемый тип), `@throws` (генерируемое исключение). Утилита `javadoc` формирует HTML-документацию.
