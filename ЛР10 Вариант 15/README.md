## Контрольные вопросы (ответы)

1. **Что такое интерфейс в Java?** Абстрактный тип данных, определяющий контракт поведения (набор методов), который должен реализовать класс. С  Java 8 содержит также default/static (Java 8+) и private (Java 9+) методы с реализацией.
2. **Можно ли создать объект интерфейса?** Нет — интерфейс нельзя инстанцировать и он не может содержать конструкторов. Допустима только ссылка на интерфейс, инициализируемая объектом класса-реализации.
3. **Какие методы могут быть в интерфейсе?** Абстрактные (`public abstract`), `default` и `static` (с реализацией, Java 8+), `private` (Java 9+).
4. **Какие поля могут быть в интерфейсе?** Только константы — неявно `public static final` (переменных состояния быть не может).
5. **Чем отличается интерфейс от абстрактного класса?** Интерфейс: без полей состояния и конструкторов, множественное наследование интерфейсов, все поля константы. Абстрактный класс: может иметь поля, конструкторы, обычные методы; наследуется только одним классом.
6. **Как класс реализует интерфейс?** Ключевым словом `implements` (+ через запятую несколько) и обязан реализовать ВСЕ абстрактные методы с модификатором не строже `public`. Иначе класс должен быть `abstract`.
7. **Может ли класс реализовать несколько интерфейсов?** Да: `class A implements B, C, D` — одновременно можно и наследовать класс, и реализовывать интерфейсы (`extends ... implements ...`).
8. **Может ли интерфейс наследовать другой интерфейс?** Да, через `extends`, причём сразу несколько: `interface C extends A, B` (множественное наследование интерфейсов разрешено). Класс-реализация реализует методы всей иерархии.
9. **Что такое default-методы?** Методы с реализацией и ключевым словом `default` (Java 8+), которые класс может унаследовать как есть или переопределить.

## Теория в коде

- `interface Assemblable`, `interface Usable` — объявление интерфейсов, абстрактные методы без тела.
- `implements Assemblable, Usable` — множественная реализация интерфейсов.
- `@Override` + `public` — реализация методов интерфейса.
- `Usable.contractInfo()` — вызов статического метода интерфейса.
- `Usable[] items` — массив интерфейсного типа, полиморфные вызовы, `instanceof` + приведение типа.
