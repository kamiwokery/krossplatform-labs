## Контрольные вопросы (ответы)

1. **Структура класса в Java:** объявление `public class Имя { ... }`, внутри — атрибуты (поля с модификаторами доступа, например `private int weight;`) и методы (описание поведения). Модификатор `public` означает доступность класса извне, имена классов пишутся с заглавной буквы.
2. **Как создаются методы класса:** сигнатура `модификатор_доступа тип_возврата имя(параметры) { тело }`. `void` — ничего не возвращает, иначе в теле должно быть `return`. Имена методов — со строчной буквы.
3. **Как создается экземпляр класса:** оператором `new` с вызовом конструктора: `Cat ourcat = new Cat();`. Переменная-ссылка того же типа позволяет вызывать методы: `ourcat.eat();`, возврат метода присваивается переменной: `String say = ourcat.speak("Play with me");`.
4. **Синтаксис класса:** `public class Cat { private int weight; private String name; public void eat() { ... } }` — модификатор доступа, ключевое слово `class`, имя, тело в фигурных скобках; каждая инструкция заканчивается `;`.
5. **Перечисление (enum):** типобезопасный набор констант, подкласс `java.lang.Enum`. Записывается `enum Role { GUEST, CLIENT, ADMIN }`. Объявляется **без** `new`, элементы инициализируются при объявлении. Может содержать поля, методы, конструкторы. Полезные методы: `values()`, `valueOf(String)`, `ordinal()`, `name()`. Запрещено: быть супер-/подклассом, абстрактным, параметризованным, создавать экземпляры через `new`.
